# SPORT LINER — с чего начать

Эта страница написана для того, кто просто хочет **открыть и посмотреть сайт**.
Никаких специальных знаний не нужно. Технические подробности — в `README.md`.

---

## Что это

Интернет-магазин тренажёров. Работает целиком, «по-настоящему»: каталог из 183
товаров с фильтрами, корзина, оформление заказа, личный кабинет с историей
покупок и панель управления, где можно добавлять и редактировать товары.

> **Сразу и честно:** это **демонстрационная версия**. Товары, цены и
> характеристики придуманы, оплата имитируется — деньги никуда не уходят.
> Подробнее — в разделе [«Что настоящее, а что имитация»](#что-настоящее-а-что-имитация).
> Пока это не исправлено, сайт нельзя открывать для покупателей.

## Шаг 1. Установить Docker (один раз)

Docker — бесплатная программа, которая запускает сайт «в коробке»: она сама
поднимет и сервер, и базу данных. Настраивать ничего не нужно.

- **Windows и macOS** — скачать **Docker Desktop**:
  https://www.docker.com/products/docker-desktop/
- **Linux** — Docker Engine + Compose:
  https://docs.docker.com/engine/install/

После установки **запустите Docker Desktop** и дождитесь, пока значок кита
в верхней панели перестанет мигать. Это значит, что Docker готов.

---

## Шаг 2. Запустить сайт

Откройте **Терминал** (macOS) или **PowerShell** (Windows), перейдите в папку
проекта и выполните две команды:

```bash
cd путь/к/папке/проекта
docker compose up --build
```

> Чтобы не набирать путь вручную: наберите `cd `, затем перетащите папку
> проекта мышкой в окно терминала и нажмите Enter.

**Первый запуск занимает 3–10 минут** — Docker скачивает нужные компоненты.
Дальнейшие запуски — несколько секунд.

Сайт готов, когда в терминале появится строка:

```
→ Starting Next.js server on port 3000...
```

### Как оформить тестовый заказ

Положите товар в корзину и заполните оформление. Данные карты — любые
правдоподобные, например:

- Номер: `4242 4242 4242 4242`
- Срок: `12/30` (любой будущий)
- CVC: `123`

Заказ появится в личном кабинете. **Деньги не списываются** — платёжной системы
в проекте нет.

### Две линейки товаров — работают по-разному

Это главная особенность каталога, сделанная под вашу схему продаж:

| | **Италия** (Technogym, Panatta) | **Китай** (UNIX Fit) |
| --- | --- | --- |
| Товаров | 81 | 102 |
| Наличие | Под заказ | В наличии |
| Цена | **Скрыта** — «Цена по запросу» | Показывается |
| Кнопка | «Запросить цену» | «Добавить в корзину» |

- Каталог **открывается с Италии** — она идёт первой везде: на главной, в каталоге
  и в каждой категории.
- Над сеткой товаров есть переключатель **«Все страны / Италия / Китай»** —
  посетитель в один клик смотрит нужную линейку.
- Цена итальянских товаров не показывается **нигде**: ни в карточке, ни в
  сравнении, ни в исходном коде страницы. Купить такой товар через корзину
  нельзя — только оставить заявку.
- Заявки с кнопки «Запросить цену» приходят в панель управления, раздел
  **«Заявки на цену»** (http://localhost:3000/admin/quote-requests): имя,
  телефон, email, комментарий и товар.

Порядок стран задаётся одной строкой в файле `src/lib/countries.ts`
(`ORIGIN_PRIORITY`), а признак «цена по запросу» можно поставить **любому**
товару галочкой в панели управления — он не привязан жёстко к Италии.

### Переключатели в шапке сайта

- **Язык** — русский / английский.
- **Страна** — Россия, Казахстан, Узбекистан, Кыргызстан. Меняет отображение
  цен. Сами цены хранятся в рублях, пересчёт — только для показа.

## Как выключить, включить и сбросить

| Что нужно                          | Команда                                          |
| ---------------------------------- | ------------------------------------------------ |
| Выключить сайт                     | `Ctrl + C` в терминале, затем `docker compose down` |
| Включить снова                     | `docker compose up` (уже без `--build`)          |
| Стереть все данные и вернуть исходный каталог | `docker compose down -v`               |

**Ваши заказы и правки товаров сохраняются** между выключением и включением.
Стирает их только команда с ключом `-v`.

### Если порт 3000 занят

Если при запуске появится ошибка `port is already allocated`, значит номер 3000
занят другой программой. Создайте рядом с файлом `docker-compose.yml` файл
с именем `.env` и одной строкой внутри:

```
APP_PORT=3001
```

Запустите снова и откройте **http://localhost:3001**.

## Где хранятся данные

Вся база данных — это **один файл**, который Docker хранит на своей «полке»
(том `db-data`), отдельно от самого сайта. Именно поэтому заказы и изменения
в товарах не пропадают при перезапуске.

В базе лежат: товары и категории, заказы, учётные записи покупателей.

При самом первом запуске база создаётся и наполняется автоматически — 183
товара и две учётные записи выше.

### Резервная копия

Если вы добавили свои товары или заказы и хотите их сохранить, скопируйте файл
базы к себе в папку проекта:

```bash
docker compose stop
docker compose cp app:/app/data/dev.db ./backup-dev.db
docker compose start
```

В папке появится файл `backup-dev.db` — это полная копия базы. Чтобы вернуть
её обратно:

```bash
docker compose stop
docker compose cp ./backup-dev.db app:/app/data/dev.db
docker compose start
```

## Что настоящее, а что имитация

Это главный раздел — прочитайте его до конца.

| Работает по-настоящему                                     | Имитация / чего нет                                                              |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Каталог, фильтры (цена, бренд, наличие, страна), сортировка, сравнение товаров | **Поиска по сайту нет** — только фильтры в каталоге                |
| Корзина и оформление заказа; заказ реально сохраняется в базу | **Оплаты нет.** Карта проверяется только на правильность формата и **не сохраняется**; заказ сразу помечается «оплачен», деньги не списываются |
| Заявки «Запросить цену» по итальянским товарам — реально сохраняются и видны в панели управления | **Уведомления о заявке не приходят** — почты нет, заявки нужно смотреть в разделе «Заявки на цену» |
| Регистрация, вход, личный кабинет с историей заказов        | **Письма не отправляются** — почтового сервера нет. Код восстановления пароля показывается прямо на экране |
| Панель управления: добавление, изменение и удаление товаров и категорий | **Загрузить фото нельзя.** У товара, созданного через панель, вместо снимка будет серая заглушка — фотографии подставляются в файлах проекта |
| Два языка и четыре страны с пересчётом цен                  | Курсы валют **условные**, зафиксированы в коде, а не берутся из банка             |
| Заказ считается по ценам из базы — подделать цену нельзя    | Списка заказов в панели управления нет, заказ видно в личном кабинете покупателя  |

### Про товары, бренды и фотографии

Названия производителей — **Technogym, Panatta, UNIX Fit** — настоящие, но
**модели, характеристики и цены придуманы** для демонстрации. Магазин не связан
с этими компаниями и ничего не продаёт от их имени. Фотографии взяты из
бесплатного фотостока Unsplash.

Поэтому сайт **намеренно закрыт от поисковых систем**: иначе выдуманные
предложения могли бы попасть в поиск и быть принятыми за настоящие. Открыть
индексацию можно одним переключателем — но только после замены каталога на
настоящий.

## Что нужно сделать перед настоящим запуском

Если вы решите превратить демо в работающий магазин:

1. **Заменить каталог** — настоящие товары, характеристики и цены вместо
   придуманных.
2. **Подключить приём оплаты** — сейчас платежей нет вообще.
3. **Сменить пароли** демонстрационных учётных записей: они опубликованы
   в документации, их знает каждый, кто её видел.
4. **Подключить почту** для восстановления пароля и отключить показ кода на
   экране (переключатель `DEMO_EXPOSE_RESET_TOKEN`).
5. **Настроить HTTPS** (защищённое соединение) и включить `SESSION_COOKIE_SECURE`.
6. **Заменить юридические тексты** — политика конфиденциальности, условия
   продажи и прочие страницы сейчас содержат демонстрационные заглушки.
7. **Решить вопрос с индексацией** в поисковых системах (`SITE_INDEXABLE`).
8. **Перевести базу на PostgreSQL**, если ожидается заметная посещаемость.

Пункты 3–7 — это настройки, менять код не требуется. Все они собраны
в файле `.env.example` и описаны в `README.md`, раздел
«Before you deploy this publicly».

## Если что-то пошло не так

| Симптом                                   | Что сделать                                                     |
| ----------------------------------------- | --------------------------------------------------------------- |
| `Cannot connect to the Docker daemon`     | Не запущен Docker Desktop — откройте его и дождитесь готовности  |
| `port is already allocated`               | Порт занят — см. раздел «Если порт 3000 занят»                   |
| Страница не открывается                   | Проверьте, что в терминале нет ошибок и он не закрыт             |
| Хочется начать «с чистого листа»          | `docker compose down -v`, затем `docker compose up --build`      |
