## Что умеет магазин

**Для покупателя**

- Каталог тренажёров с фильтрами (цена, бренд, страна, наличие, новые / б/у),
  сортировкой, сравнением товаров и поиском.
- Три способа продажи:
  - товары со склада (UNIX Fit) — с ценой, через корзину;
  - оборудование под заказ (Technogym) — «Цена по запросу» и заявка
    менеджеру;
  - б/у тренажёры — с ценой и отметкой «Б/у», раздел в меню.
- Оформление заказа: контакты, доставка или самовывоз, комментарий, согласие на
  обработку данных. Оплата — после звонка менеджера или онлайн картой/СБП
  (после подключения ЮKassa).
- Личный кабинет с историей заказов, восстановление пароля по почте.
- Русский и английский язык, цены для Казахстана, Узбекистана и Кыргызстана
  (ориентировочно, оплата в рублях).
- Страницы «Доставка и оплата», «Обмен и возврат», «Помощь покупателю»,
  «Контакты» с формой обратной связи, «Для бизнеса» с формой заявки, политика
  конфиденциальности, оферта, пользовательское соглашение.

**Для вас (админка, адрес `/admin`)**

- **Обзор** — новые заказы и заявки, выручка, чек-лист: что ещё не заполнено и
  что не подключено.
- **Заказы** — список с фильтром по статусу, карточка заказа (товары, телефон,
  адрес, комментарий), смена статуса с письмом покупателю, заметки менеджера.
- **Заявки** — запросы цены, заявки «Для бизнеса» и обратной связи, статусы
  «Новая → В работе → Закрыта».
- **Товары и категории** — добавление, редактирование, загрузка фото, галочка
  «Б/у» для бывших в употреблении.
- **Импорт / экспорт** — весь каталог в Excel и обратно.
- **Подписчики** — email-адреса из подписки в подвале, выгрузка в CSV.
- **Настройки** — телефон, почта, адрес, часы работы, реквизиты, самовывоз,
  мессенджеры. Всё сразу появляется на сайте.

Новые заказы и заявки приходят менеджеру на почту и/или в Telegram (после
настройки — см. [ЗАПУСК-ПРОДАЖ.md](ЗАПУСК-ПРОДАЖ.md), раздел 4).

> На живом сайте каталог уже настоящий: UNIX Fit с ценами и фото и Technogym
> под заказ. Если запускаете сайт у себя на компьютере (ниже), там будет
> стартовый набор из ~180 примерных товаров — он только для просмотра.

## Посмотреть сайт у себя на компьютере

### Шаг 1. Установить Docker (один раз)

- **Windows и macOS** — [Docker Desktop](https://www.docker.com/products/docker-desktop/).
  После установки запустите его и дождитесь, пока значок кита перестанет мигать.
- **Linux** — [Docker Engine](https://docs.docker.com/engine/install/).

### Шаг 2. Создать файл настроек

В папке проекта сделайте копию файла `.env.example` и назовите её `.env`.
Откройте `.env` в Блокноте и для просмотра поменяйте одну строку:

```
DEMO_ACCOUNTS=true
```

Это включит тестовые учётные записи (только для просмотра у себя — на настоящем
сервере так делать нельзя):

| Кто | Почта | Пароль |
| --- | --- | --- |
| Администратор | `admin@movigym.test` | `admin1234` |
| Покупатель | `demo@movigym.test` | `demo1234` |

### Шаг 3. Запустить

Откройте **Терминал** (macOS) или **PowerShell** (Windows), перейдите в папку
проекта и выполните:

```bash
docker compose up --build
```

> Чтобы не набирать путь: наберите `cd `, перетащите папку проекта в окно
> терминала и нажмите Enter.

Первый запуск — 3–10 минут. Сайт готов, когда появится строка
`Starting Next.js server on port 3000`. Откройте **http://localhost:3000**.
Админка — **http://localhost:3000/admin**.

Терминал должен оставаться открытым — это работающий сервер.

### Как выключить, включить и сбросить

| Что нужно | Команда |
| --- | --- |
| Выключить | `Ctrl + C`, затем `docker compose down` |
| Включить снова | `docker compose up` |
| Стереть все данные и начать с чистого листа | `docker compose down -v` |

Заказы, товары и настройки сохраняются между перезапусками. Стирает их только
команда с `-v`.

Если появилась ошибка `port is already allocated`, впишите в `.env` строку
`APP_PORT=3001` и откройте **http://localhost:3001**.

## Тестовый заказ

1. Откройте любой товар с ценой (например, в каталоге выберите «Китай»),
   нажмите «В корзину», затем «Оформить заказ».
2. Заполните имя, телефон, email и адрес, отметьте согласие.
3. Заказ появится в админке в разделе **Заказы** — откройте его и смените
   статус.

Для товаров «Цена по запросу» нажмите «Запросить цену» — заявка появится в
разделе **Заявки**.

## Если что-то пошло не так

| Симптом | Что сделать |
| --- | --- |
| `Cannot connect to the Docker daemon` | Не запущен Docker Desktop — откройте его и подождите |
| `port is already allocated` | Порт занят — см. выше про `APP_PORT` |
| Не получается войти в админку | Проверьте `DEMO_ACCOUNTS=true` в `.env` и перезапустите (`Ctrl+C`, `docker compose up`) |
| Хочется начать с чистого листа | `docker compose down -v`, затем `docker compose up --build` |
