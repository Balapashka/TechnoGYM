# Как начать продавать через SPORT LINER

Пошаговый план от «сайт готов» до «пришёл первый оплаченный заказ».
Технические детали запуска — в [README.md](README.md), обзор для заказчика —
в [НАЧАТЬ-ОТСЮДА.md](НАЧАТЬ-ОТСЮДА.md).

> Коротко: сайт технически готов принимать заказы. Чтобы продавать законно и
> без сюрпризов, нужно (1) оформить юрлицо и реквизиты, (2) заменить
> стартовый каталог на настоящий, (3) арендовать сервер в России и домен,
> (4) подключить уведомления, почту и — по желанию — онлайн-оплату.

## 1. Юридическая часть (до запуска)

| Что | Зачем | Где / как |
| --- | --- | --- |
| **ИП или ООО** | Самозанятым (НПД) нельзя перепродавать чужие товары — для магазина тренажёров нужен ИП (обычно УСН «доходы» 6% или «доходы минус расходы» 15%) или ООО. | Госуслуги / ФНС, банк при открытии счёта часто регистрирует бесплатно |
| **Расчётный счёт** | Приём оплаты от ЮKassa и по счетам от юрлиц. | Любой банк (Т-Банк, Точка, Сбер, Альфа…) |
| **Онлайн-касса (54-ФЗ)** | При оплате картой онлайн покупатель должен получить электронный чек. | Проще всего — «Чеки от ЮKassa» (включается в кабинете ЮKassa, касса не нужна). При оплате по счёту юрлицом чек не требуется. |
| **Уведомление в Роскомнадзор** | Магазин обрабатывает персональные данные (ФИО, телефон, адрес) — оператор ПДн обязан подать уведомление. | pd.rkn.gov.ru → «Уведомление об обработке ПДн», бесплатно, онлайн |
| **Реквизиты на сайте** | Закон о защите прав потребителей требует указать продавца, ИНН/ОГРН, адрес и контакты. | Админка → **Настройки** (поля со звёздочкой). Пока они не заполнены, в «Обзоре» админки висит предупреждение. |
| **Тексты документов** | Политика ПДн, оферта, условия возврата уже написаны по шаблону и подставляют ваши реквизиты автоматически. | Покажите юристу страницы `/privacy`, `/sales-conditions`, `/returns`, `/terms`. Тексты — в `src/lib/pages.ts`, дата редакции — константа `LEGAL_UPDATED` там же. |
| **Право продавать бренды** | Каталог упоминает Technogym и UNIX Fit. Для работы с брендами нужны договоры с поставщиком/дистрибьютором; фото товаров — от поставщика или свои. | Уточните у поставщиков условия использования фото и товарных знаков |

## 2. Каталог: заменить стартовые товары на настоящие

Сейчас в магазине **183 стартовых товара**: модели, характеристики и цены в них
придуманы, фото — со стока. Перед открытием продаж их нужно заменить.

**Самый быстрый путь — импорт из Excel:**

1. Админка → **Импорт / экспорт** → «Скачать каталог (CSV)».
2. Откройте файл в Excel или Google Таблицах. Одна строка — один товар.
   Описание колонок есть прямо на странице импорта.
3. Удалите строки-примеры и впишите свои товары (или поправьте существующие).
   Фото: загрузите их через форму товара в админке или укажите ссылки https://.
4. Сохраните как CSV и загрузите обратно: «Проверить файл» → «Загрузить в каталог».
   Чтобы убрать все стартовые товары, отметьте «Удалить товары, которых нет в файле».

Импорт «всё или ничего»: если в файле ошибка, ничего не меняется, а вы
видите номер строки и причину.

**Две модели продаж уже настроены:**

- **Цена на сайте + корзина** — для товаров со склада (UNIX Fit).
- **«Цена по запросу» + заявка** — для импорта под заказ (Technogym).
  Цена скрыта везде, покупатель оставляет заявку, она приходит менеджеру.
  Галочка «Цена по запросу» ставится любому товару в админке или колонкой
  `price_on_request` в файле.

## 3. Сервер и домен

**Сервер (VPS) — в России.** По 152-ФЗ базы с персональными данными граждан РФ
должны храниться на территории РФ. Подойдут Timeweb Cloud, Selectel, REG.RU,
Yandex Cloud, Beget и т. п. Хватит самого простого тарифа: 2 ядра, 2–4 ГБ ОЗУ,
20+ ГБ диска, Ubuntu 22.04/24.04 — порядка 400–900 ₽/мес.

**Домен** (`.ru` / `.рф`) — REG.RU, RU-CENTER, Timeweb и др., ~200–900 ₽/год.
В DNS домена создайте A-запись на IP сервера (для `@` и `www`).

**Установка (один раз, ~15 минут):**

```bash
# на сервере, под root
curl -fsSL https://get.docker.com | sh
git clone <адрес-репозитория> shop && cd shop
cp .env.example .env
nano .env        # заполнить по таблице ниже
docker compose -f docker-compose.prod.yml up -d --build
```

Через пару минут сайт откроется на `https://ваш-домен` — сертификат HTTPS
Caddy получит и будет продлевать сам.

**Что обязательно заполнить в `.env`:**

| Переменная | Значение |
| --- | --- |
| `DOMAIN` | `shop.example.ru` (без https://) |
| `SITE_URL` | `https://shop.example.ru` |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | ваш email и пароль администратора (10+ символов) |
| `SESSION_COOKIE_SECURE` | `true` |
| `DEMO_ACCOUNTS`, `DEMO_EXPOSE_RESET_TOKEN` | `false` |
| `SITE_INDEXABLE` | `false`, пока каталог не настоящий; потом `true` |

**Обновление сайта** после правок в коде:

```bash
cd shop && git pull && docker compose -f docker-compose.prod.yml up -d --build
```

## 4. Уведомления о заказах

Без уведомлений заказы будут видны только в админке. Настройте почту — она
работает с любого сервера.

**Почта (5 минут, прямо в админке)** — заказы и заявки менеджеру, письма
покупателю о заказе и смене статуса, ссылка для сброса пароля:

1. Заведите почту для магазина, например `sportliner@yandex.ru` (или свою).
2. Яндекс ID → «Безопасность» → «Пароли приложений» → создайте пароль для
   «Почты» (обычный пароль не подойдёт). В Mail.ru — «Пароли для внешних
   приложений».
3. Админка → **Настройки** → «Уведомления на почту» → адрес + пароль приложения
   → «Подключить». Придёт проверочное письмо.

Уведомления идут на почту из «Настроек → Email магазина», а если она пуста — на
сам этот ящик.

**Telegram (прямо в админке):**

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен бота.
2. Откройте своего бота и отправьте ему `/start` (менеджеры — тоже, или добавьте
   бота в общую группу).
3. Админка → **Настройки** → «Уведомления в Telegram» → вставьте токен →
   «Подключить». Придёт проверочное сообщение.

Новый менеджер: пусть напишет боту `/start`, затем нажмите «Добавить новых
получателей».

> Из российских дата-центров Telegram заблокирован, поэтому сайт пишет боту
> через ретранслятор за рубежом — `https://notify.sportliner.store` (отдельный
> маленький сервер в Timeweb, Нидерланды, 1 620 ₽/мес). Его адрес уже указан в
> блоке Telegram («Сервер не видит Telegram?»). Как он устроен —
> `tools/telegram-relay/README.md`.
>
> По умолчанию в Telegram приходят номер заказа, товары и сумма, а имя и
> телефон покупателя — только в админке и в письме: Telegram хранит переписку
> за рубежом, а это трансграничная передача персональных данных (152-ФЗ). Чтобы
> контакты приходили и в Telegram, отметьте «Присылать в Telegram имя и телефон
> покупателя».

## 5. Онлайн-оплата (ЮKassa) — по желанию

Без неё магазин уже работает: покупатель оформляет заказ, менеджер звонит,
подтверждает и присылает ссылку на оплату или счёт.

Чтобы принимать оплату картой/СБП сразу на сайте:

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru) как ИП/ООО, пройдите
   проверку магазина (сайт должен быть доступен по домену, с реквизитами и
   офертой — всё это уже есть).
2. В кабинете: **Интеграция → Ключи API** → `YOOKASSA_SHOP_ID` и
   `YOOKASSA_SECRET_KEY`.
3. **Интеграция → HTTP-уведомления**: адрес
   `https://ваш-домен/api/payments/yookassa`, события `payment.succeeded` и
   `payment.canceled`.
4. Для чеков 54-ФЗ подключите «Чеки от ЮKassa» и поставьте
   `YOOKASSA_SEND_RECEIPT=true`, `YOOKASSA_VAT_CODE` по вашей системе
   налогообложения (1 — без НДС для УСН).
5. Перезапустите сервер. При оформлении заказа появится «Онлайн-оплата картой
   или СБП». Оплаченный заказ автоматически получает статус «Оплачен».

Сначала проверьте на тестовом магазине ЮKassa (тестовые ключи) — карта
`5555 5555 5555 4477`, любой срок и CVC.

Рассрочку («X ₽ / мес» под ценой) включайте только после подключения
настоящей рассрочки: `NEXT_PUBLIC_INSTALLMENT_MONTHS=12` и пересборка.

## 6. Первый день работы

1. Войдите в админку `https://ваш-домен/admin` под `ADMIN_EMAIL`.
2. **Настройки** — телефон, email, часы работы, адрес, реквизиты, адрес
   самовывоза (если пусто — самовывоз не предлагается), мессенджеры.
3. **Импорт / экспорт** — загрузите свой каталог.
4. Оформите тестовый заказ сами: проверьте, что пришло уведомление в Telegram
   и письмо, смените статус заказа в админке, затем отметьте тестовый заказ
   как «Отменён» (отменённые не входят в выручку).
5. Когда каталог настоящий: `SITE_INDEXABLE=true` и перезапуск.

**Ежедневно:** раздел **Заказы** (новые подсвечены в «Обзоре») и **Заявки**
(запросы цены, «Для бизнеса», обратная связь). Меняйте статус — покупатель
получит письмо, если включена почта и стоит галочка «Сообщить покупателю».

## 7. Чтобы о магазине узнали

Всё ниже настраивается в админке → **Настройки** → «Поисковики и аналитика»,
без программиста.

- **Индексация:** галочка «Открыть сайт для Яндекса и Google».
- **Яндекс Вебмастер** (webmaster.yandex.ru) и **Google Search Console**: добавьте
  сайт, выберите подтверждение «Мета-тег», скопируйте только код из `content="…"`
  в соответствующее поле настроек, сохраните и нажмите «Проверить» в сервисе.
  Затем добавьте карту сайта `https://ваш-домен/sitemap.xml`.
- **Страницы брендов** `/brand/technogym` и `/brand/unix-fit` написаны под запросы
  «Technogym купить в Москве», «UNIX Fit Москва» — на них стоит вести рекламу и ссылки.
- **Позиции в поиске** растут постепенно (недели–месяцы): помогают карточка в
  Яндекс Бизнесе, отзывы, ссылки с других сайтов и соцсетей. Быстро попасть в
  верх выдачи можно только рекламой (Яндекс Директ).

- **Яндекс Вебмастер** и **Google Search Console** — добавьте сайт и файл
  `https://ваш-домен/sitemap.xml` (после `SITE_INDEXABLE=true`).
- **Яндекс Бизнес** (карточка на Картах) — бесплатно, приносит звонки.
- **Яндекс Метрика** — статистика посещений. Код счётчика вставляется в
  `src/app/layout.tsx` (попросите разработчика; при подключении дополните
  Политику cookie).
- **Реклама** в Яндекс Директ / VK — обязательна маркировка рекламы (ОРД),
  в Директе это делается автоматически.
- Подписчики рассылки копятся в админке → **Подписчики** → «Скачать CSV» для
  Unisender / SendPulse.

## 8. Резервные копии

База (заказы, товары, клиенты) и фото лежат в Docker-томе `db-data`.
Раз в сутки делайте копию — добавьте в `crontab -e` на сервере:

```cron
30 3 * * * cd /root/shop && docker compose -f docker-compose.prod.yml exec -T app node scripts/backup-db.mjs
```

Копии появятся в томе (`/app/data/backups`, хранятся 14 последних).
Раз в неделю скачивайте их к себе:

```bash
docker compose -f docker-compose.prod.yml cp app:/app/data/backups ./backups
```

Забыли пароль администратора — поставьте в `.env` `ADMIN_RESET_PASSWORD=true`
и новый `ADMIN_PASSWORD`, перезапустите, затем верните `false`. Или:

```bash
docker compose -f docker-compose.prod.yml exec app node scripts/create-admin.mjs you@mail.ru 'НовыйПароль123'
```
